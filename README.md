# **Student Dashboard**

## **Overview**
A simple, clean student dashboard that helps organize study life and track academic performance. The app runs in the browser, stores all data locally, and does not use third‑party services.

## **Key Features**
- `Home`
    - Quick overview of the day, welcome message, and short study tips.
- `Tasks Management`
    - Add tasks per course
    - Set due dates
    - Track incomplete tasks
    - Receive advance reminders
- `Grades Notebook`
    - Display grades by course
    - Calculate GPA/average
    - Provide basic progress analysis
- `Quick Notes`
    - Fast note-taking area for study ideas, short facts, or exam reminders
- `Weekly Timetable`
    - View and edit weekly class schedule
- `Study Tips & Stats`
    - Concise tips and simple statistics to guide study planning

## **Technical Details**
- Platform: Web-based user interface
- Design: Academic visual style focused on clarity and ease of navigation
- Storage: All data is stored locally on the user’s device (e.g., browser local storage or local files). No external servers or third‑party analytics are used.
- Target users: Students who want a lightweight, private tool to organize studies without complexity

## **Privacy & Security**
- All information stays on your device. No data is transmitted to external services.
- Not affiliated with any official institution; developed as a personal initiative.

## **Notes**
